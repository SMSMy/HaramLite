# HaramLite

![واجهة البرنامج](IMG/blank_interface.png)

برنامج مكتبي (Desktop App) مبني بأحدث التقنيات لغرض نبيل: **إزالة الموسيقى من المقاطع الصوتية والمرئية بالذكاء الاصطناعي** بكل سهولة واحترافية. يعمل البرنامج محلياً (Offline) بنسبة 100% ليحفظ خصوصيتك ويعطيك أداءً فائقاً باستخدام العتاد المتوفر لديك.

---

## أهل الفضل

هذا المشروع واقف على أكتاف ناس تعبوا قبلنا، فجزاهم الله خير:

- الملهم الأصلي: [@alganzory](https://github.com/alganzory) ومشروع [HaramMute](https://github.com/alganzory) الأساسي.
- نماذج الفصل (MDX-Net) المُدربة والمطورة عبر مشروع [Ultimate Vocal Remover (UVR)](https://github.com/Anjok07/ultimatevocalremovergui).
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) للتحميل من الإنترنت بكفاءة.
- [FFmpeg](https://ffmpeg.org/) للقص، الدمج، التحويل، والهندسة الصوتية.
- [ONNX Runtime](https://onnxruntime.ai/) لتشغيل نماذج الذكاء الاصطناعي مباشرة وبسرعة فائقة (بدون الحاجة لـ PyTorch).
- إطار العمل [Tauri](https://tauri.app/) و لغة [Rust](https://www.rust-lang.org/) لبناء واجهة سريعة وخفيفة (بديلة لـ PyQt).

## تنبيه صغير

العزل الصوتي مو سحر. إذا الموسيقى ماسكة يد الصوت ومتمشية معه في نفس الترددات، البرنامج يحاول يفكهم بأدب، لكن قد تلاحظ بعض التأثير على خامة الصوت الأصلية. استخدم وضع "مقطع عادي (Clip)" لتخفيف هذا التأثير إذا لم تكن بحاجة لإزالة فترات الصمت.

## المميزات

- **الواجهة الرسومية (GUI):** واجهة عصرية وسلسة تدعم السحب والإفلات، مع تصميم تفاعلي باللغتين العربية والإنجليزية.
- **التشغيل من سطر الأوامر (CLI):** دعم كامل للمعالجة الدفعية، الفحص، والتحميل عبر الطرفية لتسهيل الأتمتة.
- **نظام ذكي (Smart Mode):** يحلل الملف المُدخل تلقائياً، فيستخرج فيديو للملفات المرئية، وملفات MP3/WAV للملفات الصوتية، حتى عند إدراج دفعة مختلطة من الملفات.
- **وضعان للمعالجة:**
  - `أغنية (Song)`: عزل الموسيقى بشكل كامل + إضافة مؤثرات وتصفية (Revival FX) + إزالة فترات الصمت لتصبح مناسبة للمحتوى الهادف.
  - `مقطع عادي (Clip)`: للمقاطع التي تحتوي على متحدثين؛ حيث يعزل الموسيقى فقط دون قص فترات الصمت أو التعديل القوي على خامة الصوت.
- **التحميل من الإنترنت:** تكامل كامل مع `yt-dlp` يتيح لك تحميل الوسائط من مختلف المنصات (ومعالجتها مباشرة) داخل البرنامج.
- **استغلال تسريع كرت الشاشة (DirectML/GPU):** لمعالجة سريعة ونظيفة بفضل محرك `ONNX Runtime`.

## 🚀 واجهة سطر الأوامر (CLI)

لا يقتصر البرنامج على الواجهة الرسومية، بل يمكنك دمجه في برامجك وسكربتاتك من خلال سطر الأوامر المدمج في نفس الملف التنفيذي `haramlite.exe`:

### أمثلة على الاستخدام:

```bat
:: عزل الموسيقى من ملف فيديو في وضع "أغنية" 
haramlite input.mp4 -m song --video

:: معالجة دفعة من الملفات الصوتية في وضع "مقطع عادي" مع تحديد مجلد الإخراج
haramlite audio1.wav audio2.mp3 -m clip --out ./cleaned --fmt mp3

:: تحميل مقطع من يوتيوب
haramlite -u "https://youtube.com/watch?v=..." --out ./downloads

:: فحص صحة الملف (نوع الترميز واكتشاف الحاويات الوهمية)
haramlite --probe weird.mp4

:: فحص حالة النماذج والأدوات المساعدة 
haramlite --check
```

### الخيارات المتاحة:

- `-m, --mode <song|clip>` : تحديد وضع المعالجة.
- `-o, --out <DIR>` : تحديد مجلد الإخراج (الافتراضي: نفس مسار الملف أو مجلد Videos/HaramLite).
- `--both` : الاحتفاظ بمسار الموسيقى والمؤثرات كملف منفصل (Instrumental).
- `--fmt <flac|mp3|wav>` : صيغة الصوت الناتجة.
- `--video` : إخراج ملف فيديو (إذا كان المصدر مرئياً).
- `-u, --url <URL>` : تحميل مقطع من الإنترنت.
- `--update-ytdlp` : تحديث محرك التحميل.

## 🛠️ التقنيات المستخدمة

تم تصميم هذا البرنامج ليكون خفيفاً وسريعاً (كما يعكس اسمه Lite)، وتم بناؤه بالتقنيات التالية:

1. **Tauri v2:** إطار العمل الأساسي للبرنامج المكتبي.
2. **Rust:** قلب البرنامج النابض، للتعامل مع الذكاء الاصطناعي (ONNX Runtime)، الفحص (ffprobe)، ومعالجة الوسائط (FFmpeg)، بالإضافة لترتيب سطر الأوامر (CLI).
3. **TypeScript / Vite:** لتشغيل الواجهة الأمامية بأقصى سرعة ممكنة.
4. **Tailwind CSS:** لبناء الواجهة بتصميم "الزجاج" (Glassmorphism) الجذاب.
5. **خط ثمانية (Thmanyah Typeface):** لإعطاء طابع بصري عربي أصيل وجذاب مع توظيف ميزات الكشيدة المائلة.

## 🏗️ متطلبات التطوير والبناء (Development Setup)

للبناء من المصدر، تأكد من توفر المتطلبات الأساسية في بيئة Windows الخاصة بك:
- [Rust & Cargo](https://rustup.rs/)
- [Node.js](https://nodejs.org/) & [pnpm](https://pnpm.io/)

### ⚠️ ملاحظة هامة جداً للمطورين (الملفات المستثناة):
للحفاظ على خفة المستودع، تم استثناء مجلدي `bin` و `models` من الرفع على GitHub نظراً لحجمها الكبير. **يجب عليك توفيرها يدوياً** داخل مجلد المشروع الأساسي لكي يعمل البرنامج:
1. **مجلد `bin/`**: يجب أن يحتوي على `ffmpeg.exe` و `ffprobe.exe` بالإضافة إلى `yt-dlp.exe`.
2. **مجلد `models/`**: يجب أن يحتوي على نماذج الذكاء الاصطناعي (مثل `UVR-MDX-NET-Voc_FT.onnx`).

بمجرد توفير هذه المجلدات، يمكنك تشغيل بيئة التطوير:

```bat
# 1. تثبيت الحزم الخاصة بالواجهة الأمامية
pnpm install

# 2. تشغيل بيئة التطوير (يفتح نافذة البرنامج للتجربة)
pnpm tauri dev

# 3. بناء النسخة النهائية (Release)
pnpm tauri build
```
*(ستجد الملف التنفيذي الجاهز داخل `src-tauri/target/release/haramlite.exe`)*
