# تسليم الموقع الرسمي — كل ما تحتاجه لإعادة تصميمه

> موجَّه لمن يعيد تصميم الموقع (أنت أو مصمم أو أداة). كل رقم هنا **مُتحقَّق منه**،
> وما كان تخميناً لم يُكتب. الموقع الحي: <https://haramlite.com>

## 1) البنية والاستضافة

| البند | القيمة |
|---|---|
| الاستضافة | **GitHub Pages** — مجاني، HTTPS إلزامي |
| المصدر | الفرع `main` · المجلد **`/docs`** |
| الدومين | `haramlite.com` (مُشترى من Cloudflare، ملف `docs/CNAME` يحويه) |
| المرآة | `https://smsmy.github.io/HaramLite/` → تحوّل **301** إلى الدومين |
| الشهادة | Let's Encrypt تُصدرها GitHub تلقائياً · فرض HTTPS: **مفعّل** |
| زمن النشر | ~دقيقة بعد كل `git push` على `main` |

**كيف تنشر أي تعديل**: عدّل ملفات `docs/` ← `git add -A && git commit -m "..." && git push` ← انتظر دقيقة ← تحقّق.

### شجرة `docs/` (جذر الموقع)

```

google30b5f3c41dd37016.html     ملف إثبات ملكية قوقل — لا تحذفه ولا تنقله

```

### بناء تنسيقات الموقع (مهم عند تعديل الأصناف)

التصميم كُتب بأصناف Tailwind، والتنسيقات **تُصرَّف محلياً** لا من CDN:

```
site.tailwind.config.cjs   ← ثيم التصميم المُصدَّر (نفس ألوان التطبيق) + content: docs/index.html
site.input.css             ← @tailwind + @font-face للخطوط وأيقونات Material
pnpm site:css              ← ينتج docs/assets/site.css
```

**إن أضفت صنف Tailwind جديداً في `docs/index.html` ولم تُعِد التصريف فلن يعمل.**
والثيم في ملفه الخاص كي لا تمسّ تعديلات الموقع بناء التطبيق.

الواجهة المعروضة داخل الهيرو **ليست لقطة شاشة** بل **محاكاة مبنية بـHTML** صنعها
المصمم (اسم ملف ونسبة تقدّم توضيحيان). اللقطة الحقيقية محفوظة في
`assets/app-screenshot.png` — واستبدال المحاكاة بها تعديل سطر واحد إن أردت.

**قواعد الكشيدة والأحرف المرسلة** (من دليل الخط داخل المشروع `font/تعليمات استخدام الخط.md` — التزم بها حرفياً):

- **الكشيدة المائلة** (`font-feature-settings: "ss01"` وتتدرّج `ss02`…`ss05` لطول مختلف):
  تُستخدم **فقط** بين الحرف الأخير وما يسبقه في الكلمة، **كلمة واحدة في الجملة**، **مرة واحدة في الكلمة**، و**لا تجعل الامتداد أقصى طول**.
- **الأحرف المرسلة** (`"salt" 1`): لا في كلمتين متجاورتين أبداً، وقليلة جداً في الجملة.
- **مساحات بيضاء واسعة** — الواجهة نصوصها قليلة، فكل كلمة «لوحة فنية».
- الخطوط **محليّة** (`@font-face` من `assets/`) ولا تُحمَّل من Google Fonts — انسجاماً مع وعد «لا تتبّع» ولتعمل بلا إنترنت.

**الشعار النصي:** `HaramLite` — الشقّ الأول بلون النص والثاني (`Lite`) بلون الطينيّ، بخط Serif Display Black.

**الشعار (Motto):** «الموسيقى لا تليق بقلبٍ يريد الطمأنينة»
(بالإنجليزية: *Music has no place in a heart that seeks tranquillity*)

**نبرة الكتابة:** صادقة مباشرة، بلا مبالغة تسويقية. تُذكر الحدود كما تُذكر الميزات (مثال: «حد تيليجرام 50MB للإرسال و20MB للاستقبال» تُكتب صراحةً).

### وقائع المشروع التي تُبنى عليها النصوص (مُتحقَّق منها)

- **وضعان**: «أغنية» (فصل + مؤثرات إحياء + قصّ صمت) · «مقطع عادي» (إزالة موسيقى فقط).
- **المدخلات**: إفلات ملفات (فيديو/صوت) · رابط (يوتيوب وغيره) · **دفعات** بإيقاف أثناء المعالجة · **مجلد مراقبة** بحماية من امتلاء القرص.
- **المخرجات**: بجانب الملف الأصلي · MP3 أو MP4.
- **إضافة المتصفح**: زرّان في مشغّل يوتيوب («عالج هذا الفيديو» و«شاهد بعد إزالة الموسيقى») + مشاهدة تتخطّى مقاطع الصمت + إرسال أي رابط بنقرة يمين.
- **بوت تيليجرام (اختياري)**: اقتران برمز 6 أرقام (10 دقائق، 5 محاولات) · حدود **50MB إرسال / 20MB استقبال** (الروابط بلا حد) · **2GB** مع خادم Bot API محلي · خيار «الصوت فقط MP3».
- **أيقونة الشريط**: الإغلاق يُخفي إلى الشريط، والإغلاق الكامل من قائمتها.
- **الأمان**: توكن البوت و`api_hash` مشفّران بـ **DPAPI** · البيانات في **`%LOCALAPPDATA%`** · تنقيح التوكن من كل رسالة.
- **المتطلبات**: ويندوز 10/11 x64 · CUDA أو DirectML للسرعة (اختياري).
- **حالتان يجب ذكرهما بصدق**: **التحديث الذاتي موقوف** (مفتاح التوقيع غير مضبوط) · **النسخة المحمولة غير مشحونة** في 0.2.1.
- **التقنيات**: Tauri v2 · Rust · ONNX Runtime (UVR-MDX-NET-Voc_FT) · FFmpeg · yt-dlp · TypeScript/Vite · Tailwind · خط ثمانية.

## 6) البيانات الديناميكية (مهمّة — لا تُحذف في إعادة التصميم)

الصفحة تقرأ **آخر نشرة** من واجهة GitHub عند التحميل:

```
GET https://api.github.com/repos/SMSMy/HaramLite/releases/latest
```

وتُحدِّث:
1. **رقم الإصدار** في الشارة — الوسم `data-latest-version`
2. **أسماء ملفات المثبتات** في جدول التحميل — الوسم `data-latest-asset="nsis" | "msi"`
3. **روابط التحميل المباشر** — الوسم `data-dl="nsis" | "msi"` (رابط الأصل يسمح بالتنزيل المباشر)

**السلوك عند الفشل** (بلا شبكة، حدّ معدّل، JS معطّل): تبقى القيم المكتوبة في HTML،
وتشير الأزرار إلى `/releases/latest`. **مع تخزين مؤقت لكل جلسة** (`sessionStorage`)
تفادياً لتكرار الطلب.

> فائدة عمليّة: حين تنشر 0.2.2 يتحدّث الموقع وحده بلا تحرير. وإن أعدت التصميم وحذفت

## 8) قائمة التحقق بعد أي إعادة تصميم

```powershell
# 1) كل المسارات يجب أن تعيد 200 (والمستثنى 404)
foreach ($p in @('/', '/PRIVACY.html', '/LICENSE.txt', '/robots.txt', '/sitemap.xml',
                 '/404.html', '/google30b5f3c41dd37016.html',
                 '/assets/site.css', '/assets/og.png', '/assets/icon-180.png')) {
  curl.exe -sS -o NUL -w "%{http_code}  $p`n" "https://haramlite.com$p"
}
curl.exe -sS -o NUL -w "%{http_code}  /AUDIT.html (يجب 404)`n" https://haramlite.com/AUDIT.html

# 2) الدومين والتحويل
curl.exe -sS -o NUL -w "http → %{http_code} %{redirect_url}`n" http://haramlite.com/
```

وفي المتصفح:
- [ ] الشارة تعرض **آخر إصدار** (لا قيمة قديمة)
- [ ] زر التحميل **ينزّل الملف مباشرة** (لا صفحة وسيطة)
- [ ] تبديل **عربي/إنجليزي** يعمل، و`dir` يتبدّل، ويُحفظ الاختيار
- [ ] الخطوط: `document.fonts` تعرض **الخمسة** (Sans 400/500/700 + Serif 700/900)
- [ ] الصفحة صالحة على الجوال (عرض 360px) وRTL/LTR سليمان
- [ ] لا خطأ في وحدة التحكم

- **النسخة المحمولة**: بناؤها ورفعها ~250–300MB (‏`bin` 452MB + `models` 64MB) — لم تُبنَ.
- **عبارة العلامة التجارية ليوتيوب**: أُزيلت من الموقع، وما زالت في نص قائمة المتجر — قل الكلمة لتُزال هناك أيضاً.
- **أيقونات الإضافة عالية الدقة**: الموجود 16/48/128 مشتقة من رسم قديم؛ يمكن توليدها من الأصل 1254px لكن يتطلب رفع نسخة جديدة للمتجر.
